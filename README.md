# RQ Stats

Оверлей статистики для **Royal Quest Online**: DPS, підняте золото й досвід, скільки й яких мобів вбито, повний список зібраного луту.

Програма не втручається в гру: не читає її пам'ять і не перехоплює трафік. Дані беруться з чату гри двома способами:

- **з екрана**: вбудоване в Windows розпізнавання тексту читає вкладку чату кілька разів на секунду, тому цифри оновлюються наживо;
- **з файлів історії чату** (`chatlogs\*.htm`): гра записує їх із запізненням, зате точно, і програма звіряє з ними підсумки.

## Що показує

- **DPS** за останні 10 секунд, з міні-графіком;
- **Золото**: сума всіх рядків «Поднято N золота»;
- **Досвід**: сума всіх рядків «Получено опыта: N»;
- **Вбито мобів**, **Предметів**, **Рівень**;
- вкладки **Моби** (скільки вбито кожного), **Лут** (усі зібрані предмети, окремо карти) і **Бій** (нанесений та отриманий урон, лікування, макс. удар, влучність, графік урону за 2 хв);
- останні події з чату.

Статистика зберігається між запусками: після закриття й повторного відкриття програми сесія продовжується з тими самими цифрами. Почати з нуля можна кнопкою «Нова сесія».

Кожен елемент можна сховати в налаштуваннях (кнопка з повзунками), там само змінюється прозорість панелі й мова інтерфейсу: українська, російська або англійська.

## Вимоги

- Windows 10/11 з російським мовним пакетом розпізнавання тексту (зазвичай уже є, якщо встановлена російська мова);
- [Node.js](https://nodejs.org/) 18 або новіший;
- гра в режимі «вікно» або «вікно без рамки» (поверх повноекранного режиму оверлей не видно).

## Підготовка гри

1. У налаштуваннях чату додайте вкладку **Stats** і ввімкніть у ній: «Нанесённый урон», «Полученный урон», «Лечение», «Опыт», «Подбор лута».
2. Поставте галочку **«Сохранять историю сообщений»**. Тоді гра писатиме файл `chatlogs\Stats (РРРР.ММ).htm`, з яким програма звіряє підсумки.

## Запуск

```
git clone <адреса цього репозиторію>
cd rq-stats
start.cmd
```

`start.cmd` сам встановить залежності під час першого запуску.

Під час першого запуску екран затемниться: обведіть мишкою **рядки повідомлень** вкладки Stats (без кнопок вкладок угорі) і натисніть **Enter**.

## Керування

| | |
|---|---|
| Перетягування за заголовок | перемістити панель |
| **Alt+Shift+S** | сховати / показати панель |
| **Alt+Shift+R** | заново виділити чат |
| Кнопки на панелі | налаштування, виділити чат, нова сесія, згорнути, закрити |

Чат у грі не повинні закривати інші вікна, інакше програма читатиме чужий текст.

## Підрахунок з файлу

Будь-який файл історії чату можна порахувати без оверлею:

```
npm run stats -- "D:\...\Royal Quest Online\client_2962300\chatlogs\Stats (2026.10).htm"
```

## Як це влаштовано

| Файл | Що робить |
|---|---|
| `main.js` | вікно оверлею, запуск читання екрана і стеження за файлами |
| `ocr/ocr-helper.ps1` | знімає область чату і розпізнає текст (Windows OCR) |
| `src/screen-tracker.js` | порівнює знімки чату між собою, щоб кожен рядок порахувати один раз |
| `src/log-watcher.js` | стежить за папкою `chatlogs` гри |
| `src/merge.js` | поєднує дані з екрана й файлів (файл точніший, екран швидший) |
| `src/parser.js` | розбирає рядки чату (російський клієнт гри) |
| `src/stats.js` | рахує статистику |
| `overlay/` | інтерфейс оверлею і вікно вибору області чату |
