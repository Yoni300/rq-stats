# RQ Stats

Оверлей статистики для **Royal Quest Online**: DPS, поднятое золото и опыт, сколько и каких мобов убито, полный список собранного лута.

Программа не вмешивается в игру: не читает её память и не перехватывает трафик. Данные берутся из чата игры двумя способами:

- **с экрана**: встроенное в Windows распознавание текста читает вкладку чата несколько раз в секунду, поэтому цифры обновляются вживую;
- **из файлов истории чата** (`chatlogs\*.htm`): игра записывает их с задержкой, зато точно, и программа сверяет с ними итоги.

## Что показывает

- **DPS** за последние 10 секунд, с мини-графиком;
- **Золото**: сумма всех строк «Поднято N золота»;
- **Опыт**: сумма всех строк «Получено опыта: N»;
- **Убито мобов**, **Предметов**, **Уровень**;
- вкладки **Мобы** (сколько убито каждого), **Лут** (все собранные предметы, отдельно карты) и **Бой** (нанесённый и полученный урон, лечение, макс. удар, точность, график урона за 2 мин);
- последние события из чата.

Статистика сохраняется между запусками: после закрытия и повторного открытия программы сессия продолжается с теми же цифрами. Начать с нуля можно кнопкой «Новая сессия».

Каждый элемент можно скрыть в настройках (кнопка с ползунками), там же меняется прозрачность панели и язык интерфейса: украинский, русский или английский.

## Требования

- Windows 10/11 с русским языковым пакетом распознавания текста (обычно уже есть, если установлен русский язык);
- [Node.js](https://nodejs.org/) 18 или новее;
- игра в режиме «окно» или «окно без рамки» (поверх полноэкранного режима оверлей не виден).

## Подготовка игры

1. В настройках чата добавьте вкладку **Stats** и включите в ней: «Нанесённый урон», «Полученный урон», «Лечение», «Опыт», «Подбор лута».
2. Поставьте галочку **«Сохранять историю сообщений»**. Тогда игра будет писать файл `chatlogs\Stats (ГГГГ.ММ).htm`, с которым программа сверяет итоги.

## Запуск

```
git clone https://github.com/Yoni300/rq-stats.git
cd rq-stats
start.cmd
```

`start.cmd` сам установит зависимости при первом запуске.

При первом запуске экран затемнится: обведите мышкой **строки сообщений** вкладки Stats (без кнопок вкладок сверху) и нажмите **Enter**.

## Управление

| | |
|---|---|
| Перетаскивание за заголовок | переместить панель |
| **Alt+Shift+S** | скрыть / показать панель |
| **Alt+Shift+R** | заново выделить чат |
| Кнопки на панели | настройки, выделить чат, новая сессия, свернуть, закрыть |

Чат в игре не должны закрывать другие окна, иначе программа будет читать чужой текст.

## Подсчёт из файла

Любой файл истории чата можно посчитать без оверлея:

```
npm run stats -- "D:\...\Royal Quest Online\client_2962300\chatlogs\Stats (2026.10).htm"
```

## Как это устроено

| Файл | Что делает |
|---|---|
| `main.js` | окно оверлея, запуск чтения экрана и слежения за файлами |
| `ocr/ocr-helper.ps1` | снимает область чата и распознаёт текст (Windows OCR) |
| `src/screen-tracker.js` | сравнивает снимки чата между собой, чтобы каждую строку посчитать один раз |
| `src/log-watcher.js` | следит за папкой `chatlogs` игры |
| `src/merge.js` | объединяет данные с экрана и из файлов (файл точнее, экран быстрее) |
| `src/parser.js` | разбирает строки чата (русский клиент игры) |
| `src/stats.js` | считает статистику |
| `overlay/` | интерфейс оверлея и окно выбора области чата |

## Значки

Значки в `overlay/icons/` взяты с [Royal Quest Wiki](https://royalquest.fandom.com/) и принадлежат разработчикам игры (Katauri Interactive / 1C). Они используются только для узнаваемости в этом неофициальном фанатском инструменте.
